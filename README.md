# Schulnetz Redesign

A browser extension that improves the appearance and usability of Schulnetz.

It doesn't change much for now, as I'm still trying to understand how Schulnetz is structured. Once I have a better understanding of how everything works, I'll be able to make more changes and add new features.

## Features

- Redesigned interface
- Improved layout and spacing
- Customised colours and styling
- Cleaner grade overview
- Subject average name formatting
- Customisation options

## Installation

1. Download or clone this repository.
2. Extract the files if downloaded as a ZIP.
3. Open `chrome://extensions` in your browser.
4. Enable Developer mode.
5. Select **Load unpacked**.
6. Select the extension folder.

## Compatibility

Designed for Schulnetz and tested with its web interface.

## Privacy

The extension modifies the appearance of Schulnetz locally in the browser. It does not require an external account.
